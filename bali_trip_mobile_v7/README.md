# Bali Trip App v7

Mobile-first Bali travel PWA.

Changes from v6:
- Weekly calendar long-press reduced from 1.5s to 1.0s.
- Dragging now keeps the original calendar event block shape, size, color, and text style, similar to Google Calendar.
- New Bali vacation visual theme: ocean turquoise, warm sand, sunset coral, palm green.
- v6 local data migrates into v7 automatically when deployed to the same origin.

Deploy:
Replace the current repository root files with the files in this folder and commit to `main`.
Once the Vercel project is connected to that Git repository, each commit to the production branch redeploys automatically.
